# Проценка запчастей

Веб-приложение для поиска автозапчастей и их аналогов с использованием API сервиса Favorit Parts.

## Стек технологий

- React 19
- TypeScript
- Vite
- Redux Toolkit (RTK Query)
- Bootstrap 5.3
- Biome (линтер и форматтер)
- Lodash (debounce)

## Архитектура (Feature-Sliced Design)

Проект организован по методологии Feature-Sliced Design (FSD). Это позволяет легко масштабировать код и избегать циклических зависимостей.

Структура слоев:

```
src/
├── api/ # Базовый инстанс RTK Query, OpenAPI и сгенерированный клиент
├── app/ # Инициализация приложения, провайдеры и глобальные стили
├── pages/ # Страницы приложения (точки входа)
│ 	└── main/ # Главная страница
├── widgets/ # Крупные блоки, объединяющие фичи и сущности
│ 	└── price-calculator/ # Виджет оркестрации поиска и отображения
├── features/ # Действия пользователя
│ 	├── search-by-number/ # Ввод артикула с debounce
│ 	└── select-brand/ # Выбор производителя из списка
├── entities/ # Бизнес-сущности проекта
│ 	└── goods/ # Сущность товара (таблица предложений, логика выбора склада)
├── shared/ # Переиспользуемая инфраструктура (утилиты, конфиги)
└── main.tsx # Точка входа Vite
```

## Генерация API через RTK Query

Клиент для работы с API генерируется автоматически на основе спецификации OpenAPI (файл `src/api/openapi.yaml`).

Для генерации используется пакет `@rtk-query/codegen-openapi`. Конфигурация находится в файле `openapi-config.json`.

Чтобы обновить типы и хуки после изменения YAML-файла, выполните команду:
`npm run api:generate`

Эта команда не только генерирует файл `src/api/favoritPriceApi.ts`, но и автоматически прогоняет его через Biome для приведения к единому стилю кода.

## Основные команды

- `npm run dev` — запуск сервера разработки (Vite).
- `npm run build` — сборка production-версии проекта.
- `npm run api:generate` — генерация API клиента из OpenAPI и его форматирование.
- `npm run lint` — проверка кода линтером Biome.
- `npm run lint:fix` — автоисправление ошибок линтера Biome.
